# Curated UNIKMO images

The `/curated` page currently uses existing site photos as placeholders so the page
looks complete. To use the 6 supplied curated images, drop them in this folder with
the names below, then update the matching `src` paths in `app/curated/page.tsx`
(and, if you want, `components/CuratedCheckout.tsx` has no images).

| Filename                      | Image                                                              | Placeholder it replaces on /curated |
|-------------------------------|-------------------------------------------------------------------|-------------------------------------|
| `times-square-night.webp`     | Wedding couple on Nasdaq at night, friends toasting               | hero left  (`/curated-anniversary-billboard.webp`) |
| `keep-it-card.webp`           | UNIKMO card flat-lay with printed photos, dog photo, phone        | hero right (`/card-front.png`) + Keep It card (`/story/she-watches.png`) |
| `show-it-card.webp`           | Hand holding a UNIKMO card in front of a Times Square billboard   | Show It card (`/curated-anniversary-billboard.webp`) |
| `share-keepsakes.webp`        | Four hands holding matching UNIKMO cards over a table             | Share It card (`/email-product-triptych.png`) |
| `times-square-proposal.webp`  | Proposal on Nasdaq, red roses                                     | Times Square section left (`/curated-anniversary-billboard.webp`) |
| `times-square-day.webp`       | Wedding couple on Nasdaq in daylight                              | Times Square section right (`/occasions/anniversary.png`) |

Also upload matching images to the 3 Shopify products
(Curated UNIKMO — Keep It / Show It / Extra Keepsake Card) in the Shopify admin.
